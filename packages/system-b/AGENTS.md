# System B package rules

System B is contrasty, expressive, and editorial in a different register. Keep
surfaces dark and ink-bright, reserve coral for action, use cyan for focus, and
let motion feel physical without becoming distracting. All visual decisions live
in this package's tokens and stylesheet; consuming apps should compose the
components rather than replace their visual language.

The public API is the eight V1 primitives plus their documented compound
subcomponents. Shared behavior and class-name composition come from
`@prism-system/ui-core`; System B owns every color, type, radius, shadow, state, and
motion value.
