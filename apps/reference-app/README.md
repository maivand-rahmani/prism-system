# Reference App

The Reference App is a fixed, static dashboard composition. Its only state is the
selected registered design system; the same JSX tree is rendered for either package so
visual differences remain attributable to the system.

- The selected system is resolved through the generated `app/registry.ts` (tool-owned,
  regenerated by `pnpm ds:register <id>` from `config/design-systems.json`); the app
  imports only public `@prism-system/*` package names and never package internals.
- The composition is rendered from the shared required component surface through public
  props only. Layout, placement, and reference scenarios belong to the app; the visual
  language belongs to the design system.
- What each system provides — required components, optional capabilities, variants,
  sizes, and compound members — is published in its generated `design-system.json`
  manifest (`<package>/manifest`) and shown in the Showcase at `/showcase/<id>`.

Run it from the workspace with `pnpm --filter @prism-system/reference-app dev`.
